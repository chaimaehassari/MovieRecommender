## Organisation des branches

- main : version stable du projet.
- develop : branche d'intégration.
- feature/* : développement des fonctionnalités.
- release/* : préparation d'une version.
- hotfix/* : correction urgente en production.

## Règles de contribution

1. Créer une branche de fonctionnalité depuis develop.
2. Utiliser des messages de commit conventionnels : feat, fix, docs, test, refactor ou chore.
3. Tester le code avant de proposer une Pull Request.
4. Ouvrir une Pull Request vers develop.
5. Faire réviser chaque Pull Request par un autre membre.
6. Ne jamais fusionner sa propre Pull Request.
7. Ne jamais pousser directement sur main ou develop.
